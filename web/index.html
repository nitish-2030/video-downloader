        Settings
        
      
    
        
    
    
    
    
    
        
      
      
      
        
        
          
          
        1. In your browser, install the extension called "Get cookies.txt LOCALLY"
            (search your browser's extension store for that exact name).
          2. 
          
        2. Go to youtube.com, signed in to the account you want to use.
          3. 
          
        3. Click the extension's icon and choose Export. It saves a file for
            you, usually into your Downloads folder.
          4. 
          
        4. The saved file's name doesn't matter — it depends on the site and can come out as
            something like youtube.com_cookies.txt, not always plain "cookies.txt".
            You don't need to rename it: just click Browse... above and pick
            whatever file it saved.
          5. 
        
        
        
        If a restricted video stops working later, your sign-in has likely
          expired — export a fresh file the same way and Browse to it again.
